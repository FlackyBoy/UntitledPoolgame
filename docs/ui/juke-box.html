Juke-box

Le juke-box du bar sert de menu : on choisit une sélection (A1, A2…), les modes sont des disques qu'on sort de leur pochette, J2 rejoint en glissant une pièce. En partie, J1 est la face A, J2 la face B, la jauge est un VU-mètre, une faute fait rayer le disque.

    L'idéeUn objet iconique du bar qui fait tout : menus, arrivée des joueurs (la pièce), choix des modes (les disques). Le vocabulaire musical rend les modes et les dimensions amusants à parcourir : faces, maxi, face cachée pour les dimensions à débloquer.
    En partieFace A / face B pour les joueurs, disque qui tourne quand c'est ton tour, billes restantes comme une liste de titres, pouvoir en stock = « prochain titre », VU-mètre pour la puissance ; le son peut suivre (égaliseur qui réagit, scratch à la faute).
    Dans UnityUn vrai juke-box 3D dans le bar pour le menu principal (caméra qui s'en approche), HUD en Canvas ; l'égaliseur peut lire le spectre audio de la musique du bar (AudioSource.GetSpectrumData).
