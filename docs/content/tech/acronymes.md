## Termes techniques sans sigle

| Terme | Définition | Source |
|---|---|---|
| **Bend goal** | Point vers lequel un coude ou un genou est orienté par l'IK | [Final IK](http://www.root-motion.com/finalikdox/html/index.html) |
| **Cascade d'ombres** | Découpage de la distance en plusieurs shadow maps | [Unity — cascades](https://docs.unity3d.com/Manual/shadow-cascades.html) |
| **Forward+** | Rendu direct avec tri des lumières par tuiles d'écran | [Unity URP](https://docs.unity3d.com/Manual/urp/rendering-paths-comparison.html) |
| **Kinematic** | Rigidbody déplacé par le code, ignoré par les forces | [Unity](https://docs.unity3d.com/ScriptReference/Rigidbody-isKinematic.html) |
| **Mipmap** | Versions réduites d'une texture pour l'affichage au loin | [Wikipédia](https://fr.wikipedia.org/wiki/MIP_mapping) |
| **PhysX** | Moteur physique utilisé par Unity | [Wikipédia](https://fr.wikipedia.org/wiki/PhysX) |
| **Ragdoll** | Personnage animé par la physique (poupée de chiffon) | [Wikipédia (en)](https://en.wikipedia.org/wiki/Ragdoll_physics) |
| **Shader** | Programme exécuté par le GPU pour le rendu | [Wikipédia](https://fr.wikipedia.org/wiki/Shader) |
| **Shadow map** | Image de profondeur vue depuis la lumière, pour les ombres | [Wikipédia (en)](https://en.wikipedia.org/wiki/Shadow_mapping) |
| **Skinning** | Déformation d'un maillage par un squelette | [Wikipédia (en)](https://en.wikipedia.org/wiki/Skeletal_animation) |
| **Split-screen** | Écran partagé entre plusieurs joueurs | [Wikipédia (en)](https://en.wikipedia.org/wiki/Split_screen_(video_games)) |
