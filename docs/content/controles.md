# Contrôles

> Tels que configurés dans `InputSystem_Actions_Local` (asset d'input du mode local). Manette : noms Xbox / PlayStation. Le détail des coups (queue, poing, pied) et de leurs réglages est dans l'onglet *Réglages combat*.

## Récapitulatif des touches

| Action | Clavier / souris | Manette |
|---|---|---|
| Se déplacer | ZQSD / WASD, flèches | Stick gauche |
| Regarder | Souris | Stick droit |
| Interagir | E | Y / △ |
| Attaque (tir, lancer, coup de queue) | Clic gauche, Entrée | X / □ |
| Poing | Clic gauche | RB / R1 |
| Pied | Clic droit | RT / R2 |
| Utiliser le pouvoir | F | X / □ ⚠️ |

## Selon la situation

| Situation | Clavier / souris | Manette | Effet |
|---|---|---|---|
| **Mains vides** | Clic gauche | RB / R1 | Poing : part au clic (spammer pour enchaîner, mains alternées) ; pas de coup chargé |
| | Clic droit | RT / R2 | Pied : clic bref = coup de pied, maintenir = coup de pied chargé (≥ 80 % : **spartiate**) |
| | E | Y / △ | Ramasser l'objet ou la queue regardé |
| **Objet en main** | Clic gauche (maintenir, relâcher) | X / □ | Charger puis lancer l'objet dans la direction du regard |
| | E | Y / △ | Poser l'objet |
| | Clic droit | RT / R2 | Coup de pied |
| **Queue en main, hors visée** | Clic gauche (maintenir, relâcher) | X / □ | Coup de queue : tourner pendant la charge choisit le coup (droite → balayage vers la gauche, gauche → vers la droite, haut → vertical, rien → estoc) |
| | E près de la blanche arrêtée | Y / △ | Entrer en visée (son tour) · sinon poser la queue |
| | Clic droit | RT / R2 | Coup de pied |
| **En visée** | Souris | Stick droit | Tourner autour de la bille |
| | ZQSD | Stick gauche | Déplacer le point de frappe (effet) |
| | Clic gauche (maintenir, relâcher) | X / □ | Charger puis tirer |
| | E | Y / △ | Sortir de la visée |
| **Main libre / annonce de poche** (vue de dessus) | ZQSD | Stick gauche | Déplacer la bille / changer de poche |
| | E | Y / △ | Valider |
| **Mode Party** | F | X / □ | Utiliser le pouvoir en stock |

> ⚠️ Sur manette, **Attaque et Utiliser le pouvoir sont sur le même bouton** (X / □) : charger un tir ou un coup de queue active aussi le pouvoir. La TODO mentionne « touche 2 / croix droite » pour le pouvoir, ce qui ne correspond plus à l'asset. À corriger.

Sauter, Sprint, S'accroupir et Précédent sont définis dans l'asset mais non utilisés par le jeu.

## Raccourcis de test

- Maintenir **C+P** : un second joueur rejoint la partie.
- **C+W** : saute directement à la fin d'une partie de 8-ball (groupes vidés).
